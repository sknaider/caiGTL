## Decision Matrix

### When to Choose GTL AI Security

✅ **Best fit for:**
- Logistics and supply chain companies
- Companies in Peru/Latin America (SUNAT compliance)
- Mid-size organizations (50-500 employees)
- Budget-conscious security teams
- Need for continuous automated scanning
- Industry-specific security requirements (EDI, WMS, GPS)
- Spanish-speaking security teams

❌ **Not ideal for:**
- Enterprise > 1000 employees (consider Tier 3 or Darktrace)
- Needs sub-second threat detection (Darktrace/Vectra better)
- Highly regulated environments (healthcare, finance) - wait for certifications
- Companies requiring FedRAMP/HITRUST (not yet certified)

### When to Choose Darktrace

✅ **Best fit for:**
- Large enterprises (1000+ employees)
- Financial services (banking, insurance)
- Need for AI-powered autonomous response
- Real-time threat detection critical
- Advanced insider threat detection

❌ **Not ideal for:**
- Small/mid-size companies (cost prohibitive)
- Budget < $100K/year
- Logistics-specific security needs
- Spanish language requirement

### When to Choose Vectra AI

✅ **Best fit for:**
- Network-centric security focus
- Cloud workload protection (AWS, Azure, GCP)
- Large IT infrastructure
- Advanced persistent threat (APT) detection

❌ **Not ideal for:**
- Application security needs
- Small/mid-size companies
- Compliance automation requirements
- Logistics industry specifics

### When to Choose Manual Pentesting

✅ **Best fit for:**
- Annual compliance requirements (PCI-DSS, HIPAA)
- Pre-production security validation
- M&A security due diligence
- Deep technical expertise needed

❌ **Not ideal for:**
- Continuous monitoring needs
- Budget > $100K/year
- Fast-changing environments (DevOps, cloud)
- Resource-constrained teams
