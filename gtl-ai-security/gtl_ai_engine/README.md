## 🎓 Training Your Models

### Step 1: Collect Data
```bash
# Collect vulnerability data
python collect_vuln_data.py --source nvd,cve,exploit-db

# Collect code samples
python collect_code_data.py --repos top-1000-security

# Collect malware samples
python collect_malware.py --sources virusshare,malshare
```

### Step 2: Prepare Dataset
```bash
# Preprocess and clean data
python prepare_dataset.py --task vulnerability-analysis

# Split train/val/test
python split_dataset.py --ratio 0.8/0.1/0.1
```

### Step 3: Train Model
```bash
# Fine-tune Llama on your data
python train_model.py \
  --model llama-3.1-70b \
  --task security-analysis \
  --epochs 3 \
  --gpu 0 \
  --batch-size 4
```

### Step 4: Evaluate
```bash
# Test model performance
python evaluate_model.py --checkpoint best_model.pt
```

### Step 5: Deploy
```bash
# Deploy to production
python deploy_model.py --model best_model.pt --endpoint /api/ai/analyze
```

## 🚀 Quick Start

### Prerequisites
```bash
# Install CUDA toolkit
sudo apt install nvidia-cuda-toolkit

# Install PyTorch with CUDA
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

# Install Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Pull models
ollama pull llama3.1:70b
ollama pull codellama:34b
```

### Installation
```bash
cd gtl_ai_engine
pip install -r requirements.txt
python setup.py install
```

### Basic Usage
```python
from gtl_ai_engine import AISecurityAnalyzer

# Initialize analyzer
analyzer = AISecurityAnalyzer(
    model="llama3.1:70b",
    gpu_id=0
)

# Analyze vulnerability
result = analyzer.analyze_vulnerability(
    title="SQL Injection in login form",
    description="User input not sanitized",
    context={"framework": "Django", "version": "4.2"}
)

print(result.risk_score)          # 9.2
print(result.exploit_complexity)  # "Low"
print(result.remediation_steps)   # ["Use parameterized queries", ...]
print(result.poc_code)            # Generated exploit PoC
```

## 🤝 Integration with GTL Scanner

```python
from gtl_security_scanner import SecurityScanner
from gtl_ai_engine import AIEnhancer

# Regular scan
scanner = SecurityScanner()
results = scanner.scan("https://target.com")

# Enhance with AI
ai_enhancer = AIEnhancer()
enhanced_results = ai_enhancer.enhance(results)

# Get AI insights
for vuln in enhanced_results.vulnerabilities:
    print(f"Vulnerability: {vuln.title}")
    print(f"AI Risk Score: {vuln.ai_risk_score}")
    print(f"Exploit Chain: {vuln.exploit_chain}")
    print(f"AI Remediation: {vuln.ai_remediation}")
    print(f"Business Impact: {vuln.business_impact}")
```
