## 🚀 Inicio Rápido

### Prerequisitos
```bash
# Instalar CUDA toolkit
sudo apt install nvidia-cuda-toolkit

# Instalar PyTorch con CUDA
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

# Instalar Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Descargar modelos
ollama pull llama3.1:70b
ollama pull codellama:34b
```

### Instalación
```bash
cd gtl_ai_engine
pip install -r requirements.txt
python setup.py install
```

### Uso Básico
```python
from gtl_ai_engine import AISecurityAnalyzer

# Inicializar analizador
analyzer = AISecurityAnalyzer(
    model="llama3.1:70b",
    gpu_id=0
)

# Analizar vulnerabilidad
result = analyzer.analyze_vulnerability(
    title="SQL Injection en formulario de login",
    description="Input del usuario no sanitizado",
    context={"framework": "Django", "version": "4.2"}
)

print(result.risk_score)          # 9.2
print(result.exploit_complexity)  # "Baja"
print(result.remediation_steps)   # ["Usar consultas parametrizadas", ...]
print(result.poc_code)            # PoC de exploit generado
```

## 🤝 Integración con GTL Scanner

```python
from gtl_security_scanner import SecurityScanner
from gtl_ai_engine import AIEnhancer

# Escaneo regular
scanner = SecurityScanner()
results = scanner.scan("https://objetivo.com")

# Mejorar con IA
ai_enhancer = AIEnhancer()
enhanced_results = ai_enhancer.enhance(results)

# Obtener insights de IA
for vuln in enhanced_results.vulnerabilities:
    print(f"Vulnerabilidad: {vuln.title}")
    print(f"Score de Riesgo IA: {vuln.ai_risk_score}")
    print(f"Cadena de Exploit: {vuln.exploit_chain}")
    print(f"Remediación IA: {vuln.ai_remediation}")
    print(f"Impacto de Negocio: {vuln.business_impact}")
```
